## Project Overview

This is a client-only React application built with Vite, TanStack Router, and TanStack Query. It demonstrates authentication, route protection, and file-based routing patterns.

## Commands

```bash
# Development
pnpm dev              # Start dev server on port 3000

# Build
pnpm build           # Build for production
pnpm preview         # Preview production build

# Testing
pnpm test            # Run Vitest tests
```

Use `pnpm` as the package manager (required version: 10.28.2+).

## Architecture

### Routing

File-based routing using TanStack Router. Routes are defined in `src/routes/`:

- `__root.tsx` - Root route with HTML shell and devtools only (no page layout/chrome)
- `_auth/route.tsx` - Authenticated guard route with `beforeLoad`; it should generally render only `<Outlet />`
- `_auth/app/route.tsx` - Authenticated app-center layout for `/app` pages; renders app chrome and navigation
- `_auth/app/users/$userId/` - Dynamic parameter routes under auth
- `login.tsx` - Standalone login page with independent layout (not wrapped by app-center layout)

Key routing patterns:
- Use `createFileRoute()` to define routes
- Keep `__root.tsx` minimal; place product-specific UI layout in nested layout routes (for this repo, `_auth/app/route.tsx`)
- Use `beforeLoad` in `_auth/route.tsx` to guard all nested authenticated routes
- Layout routes export a component that renders `<Outlet />` for nested routes
- Pathless/layout grouping routes use underscore prefixes (for example `_auth/`, `_pathlessLayout/`)

### Authentication

Auth context in `src/auth.tsx`:
- `AuthProvider` wraps the app in `src/main.tsx`
- Auth state passed to router via context
- Access in routes via `context.auth`
- `useAuth()` hook for component access
- User persisted in localStorage

### Router Context

Router defined in `src/router.tsx` with:
- `queryClient` from TanStack Query
- `auth` from AuthProvider
- Access in routes: `Route.useRouteContext()` or via `context` param in loaders/beforeLoad

### Path Aliases

Import paths use `#/*` alias (configured in `package.json` and `tsconfig.json`):
```tsx
import { foo } from '#/utils'
```

## Generated Files

`routeTree.gen.ts` is auto-generated by the router plugin. It is marked as readonly in `.vscode/settings.json` - do not edit manually.

## Styling

Tailwind CSS v4 via Vite plugin. Theme toggle implemented in `src/components/ThemeToggle.tsx` with localStorage persistence.
